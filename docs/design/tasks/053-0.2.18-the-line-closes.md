# 053 — 0.2.18: the 0.2.x line closes, and one published number was the retracted one

**Branch:** `main`. **Register entries touched:** `024.38`, `024.39`,
`024.45`, `024.62`, `024.71`, `024.121`, `024.150`, `024.275`, `024.284`.

At the start of this release nine entries were targeted at 0.2.18. At the
end **no open entry is targeted at any 0.2.x version**, and the 34
user-visible open findings are each disclosed in both languages, with no
entry appearing in one language only.

0.2.x existed to make what the project says it can do actually true. This
release found one place where it still was not, and it was not a
capability.

## The one that mattered: the latency users were told about was wrong

`KNOWN_LIMITATIONS` published 2.1 s and 5.3 s, in both languages, from
0.2.1 to 0.2.17. Those figures came from the five-`didChange`-minus-none
method that `024.45` **had already retracted in the register** — since
0.2.10 five edits with no read between them coalesce into one analysis
while the baseline already analyses on `didOpen`, so the difference is
near zero whatever an analysis costs. It measured the coalescing.

The retraction was written down and never carried to the document. That
is `CLAUDE.md`'s "a revert is the change most likely to leave
documentation behind", arriving through a correction rather than a
revert, and it is the class this whole line exists to close.

Corrected in both languages, with the method named and the old figures
explained rather than quietly swapped: **3.9 s / 2.7 s / 4.7 s**, one
re-analysis on a warm server, median of five.

## What was built

**`scripts/ci_status.rb`** (`024.284`). One line after preflight's
verdict saying what CI last said about the branch. It exits 0 in every
case, including the ones it cannot answer, because neither "no network"
nor "no `gh`" says anything about the tree — which is why it is not a
tenth check. It covers the extension gap better than running the
extension locally would: CI runs `vscode/`'s suites and the packaged
Core, and the `spec/meta` examples that refuse a partial tree are only
ever observable through CI, because a local clone is never partial.

**A declared relationship between `AGENTS.md` and `CLAUDE.md`**
(`024.150`). Twelve bullets name the section they restate, and a spec
fails when `CLAUDE.md` no longer has one. The entry had been open
because the *inferred* form measured three false positives in eleven; a
declaration has none, without an exception list.

**A flake that captures itself** (`024.275`). The entry's instruction —
"the next run that reproduces it captures the failure message before
anything else" — addressed whoever was watching, and nobody was, twice,
across two releases. It is attached to the assertion now.

## Three defects found by checks this repository already had

Each was in code written *in this release*, and each was caught by a
mechanism rather than a reviewer:

- a pipe arriving as US-ASCII escaped a `rescue JSON::ParserError`, and
  the meta example requiring `scripts/utf8.rb` of every script named the
  layer that owns it;
- a bare `git` spawn an inherited `GIT_DIR` could have aimed elsewhere,
  caught by the spawn-scrubbing example;
- the paragraph explaining `024.150`'s markers spelled one the way a real
  one is spelled, so the new scanner read it as a marker — **in the
  commit that wrote the scanner**. That is `CLAUDE.md`'s "writing a check
  means writing bait for the other checks", and it was found by the check
  rather than by a person, which is the whole argument for writing them.

## What was measured and not taken

- `%i[class module]` is reallocated on each of **710,425** `SymbolId`
  constructions per analysis, and a frozen constant is 28% faster on that
  line — **7 ms of 2,688**. Not taken: `CLAUDE.md` records that 0.1.12
  lost a round to logic moved into that exact constructor.
- Memoising `qualify_owner` removed **1,961,027** allocations per
  analysis (385 distinct inputs) and bought **4.5–5.3%**. Taken, and
  recorded as the second time this entry has found that a call count says
  how often something happens, not what it costs.

## One correction to a claim this project made about itself

`024.121` said five decisions in `measured_claims_spec.rb` "could not be
pinned at all". Four were inverted by hand: every one is caught, by a
second example in the same file — which is what
`check_pinned_mutations.rb`'s own header prescribes for a spec, and for a
stated reason. The manifest's silence there is a scope decision, not a
hole. The sentence was written in the release that found the shape, read
true, and was never run against the tree.
