# Task 033: 0.2.5 — the foundations, and the answers that rested on them

The release the maintainer redefined 0.2.4 into and then had to give up
the number for: a security patch took 0.2.4 (see `031`), and this became
0.2.5. Its goal is `032`'s, verbatim from the maintainer; `029` holds
candidate items produced under a narrower reading and is not the scope.

**Everything here was chosen against two axes and nothing else** — the
general safety obligations that shipping a product creates, and section 0
of `docs/design/docs/01-product-requirements.md`. Where an audit finding
could not be tied to one of them it was left alone, however real.

## What shipped

### Axis A — obligations that hold whether or not section 0 mentions them

**Workspace Trust gates everything that executes.** Trust was read out of
the `initialize` params at `maybe_start_agent` and never kept, so the
three other paths to code execution never asked: restarting the Agent,
`runObservedTests` with a caller-supplied command, and loading a static
plugin. Reproduced before fixing. One predicate now, failing closed
before `initialize` has been handled at all. Six existing examples
encoded the ungated contract — one of them asserting that an untrusted
restart *should* be acknowledged, which was the hole written down as a
requirement.

**The cache is owner-only.** `vscode/PRIVACY.md` says it holds method
bodies from the user's source; it was created at the umask's 0755.
`Observation::Runner` already wrote the same evidence through `Tempfile`,
owner-only — so the project's standard for this data was already stricter
than what its long-lived copy got.

**The shipped artifact is inspected.** The `$HOME` check had never run
against the build a user installs: CI greps an ubuntu-built VSIX, a
different build with different vendored extensions, and the Apple Silicon
workflow had no such step. `release.sh` does it now and refuses on a hit,
calling `/usr/bin/grep` by absolute path — the bare name resolves to a
ugrep wrapper on this machine and skips binary files, which produced a
withdrawn register entry in 0.2.3.

**`release.sh` refuses a token file readable beyond its owner**, which it
had documented and never checked.

### Axis B — section 0's core

Two wrong answers in the thing 1.0.0 *is* — type tracking and method
resolution. Both were **measured before being fixed**, because 0.4 says
frequency decides and estimating is not measuring.

| Defect | Frequency | Verdict |
|---|---|---|
| `scope` named its relation by the owner's last path segment | 63 of 66 `scope` declarations in the gem corpus are namespaced; 13.6% of class basenames are shared across namespaces | ordinary path — fixed |
| RBS type names truncated to their last segment | 240 of 334 loaded RBS types are nested; 27 of their basenames are also classes in the gem corpus | ordinary path — fixed |

The second was one line, and its blast radius was measured rather than
assumed: the whole suite, one failure, which is `Mutex` now answering
`Thread::Mutex`. That is what it is, and the example says so rather than
being silenced.

Both lines were **unpinned** in the sense CLAUDE.md means: every existing
fixture used a top-level class, where the two candidate behaviours give
the same string. The new fixtures use two namespaces holding the same
name — the only shape that can tell them apart.

### Rules that were working against section 0

**The review gate.** "Repeat until a round comes back clean" measured
reviewer exhaustion: `028` declares merge round 8 clean and the next
entry is an external reviewer finding two defects; roughly sixty rounds
are recorded across 0.2.x. A procedure meant to raise accuracy, that does
not measure accuracy and pushes the release away, is 0.4's own failure
arriving through machinery built to serve it. Replaced with a checkable
form — fresh reviewer, method the previous round did not use, method
enumerated — and bounded at three rounds, after which the release ships
with its open findings recorded.

**The register became searchable.** 72 entries, ~4,300 lines, 25 out of
numeric sequence. `scripts/reindex_findings.rb` sorts and generates the
index; the spec calls the script rather than reimplementing it.

## Deliberately not done

- **`024.73`** — `Marshal.load` on plugin output defeats the fork
  boundary. JSON does not fit: declarations legitimately carry real type
  objects. Needs a protocol change; loading a plugin is gated on trust
  meanwhile.
- **The register's retention rule.** Entries are almost never deletable
  because the standard fix leaves a citing comment, so 0 of 72 have been
  removed and the file only grows. That is a change to the citation
  convention, larger than making the file findable.
- **Case-insensitive home-path matching.** Tried, and reverted on
  measurement: it flags 37 lines of ordinary `app/views/users/...`. A
  check that cries wolf 37 times is one people switch off. The rejected
  variant is pinned as *not* matched so the decision reads as a decision.
- **`024.47`'s naming convention decision**, and the remaining `029`
  items. Recorded, not attempted.
