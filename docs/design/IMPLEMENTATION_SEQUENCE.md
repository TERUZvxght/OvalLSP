# OvalLSP Task 009以降の実装順序

## 1. 基本方針

- Task 009〜013でRuby意味解析とLSP利用面を完成させる。
- Task 014〜016で参照系機能を追加する。
- Task 017〜019でRails・Gem・実行時情報を拡張する。
- Task 020〜022で配布、性能、互換性を製品レベルへ引き上げる。
- 各Taskは単独でテスト可能かつgreenで終える。
- 後続Taskのための過剰な先行抽象化を禁止する。
- Core経路へAI推論やネットワーク依存を入れない。

## 2. 推奨マイルストーン

### 0.3-alpha completion

### 0.5-beta

### 0.7-beta

実行時観測と一般ユーザー向けVSIX配布が成立する。

### 0.9-rc

### 1.0
